# 👕 مشروع تصاميم براند ملابس ستريت وير (Streetwear Brand Designs)

مرحباً بك! هذا المجلد يحتوي على ملفات التصاميم الاحترافية لمنتجاتك بجودة عالية وخلفية شفافة تماماً جاهزة للرفع المباشر على منصة شوبيفاي (Shopify).

---

## 📁 هيكلية الملفات (File Structure)

تم تنظيم كل موديل تيشيرت في مجلد مستقل باسم الكود الخاص به (مثال: `TSH-01`). داخل كل مجلد، ستجد الـ 5 صور المطلوبة بصيغة **PNG بخلفية شفافة**:

```text
📁 streetwear-designs/
│
└─── 📁 TSH-01/                   <-- كود الموديل الأول (تيشيرت أسود بطبعة اليد الحمراء)
     ├── 🖼️ 3d_mannequin.png     <-- تيشيرت مجسم 3D / Flat-lay بخلفية شفافة
     ├── 🖼️ pose_1.png           <-- وضعية 1: وقوف أمامي مسترخي (Front View)
     ├── 🖼️ pose_2.png           <-- وضعية 2: وقوف جانبي بزاوية 45 درجة (Side/Profile View)
     ├── 🖼️ pose_3.png           <-- وضعية 3: استعراض من الخلف (Back View)
     ├── 🖼️ pose_4.png           <-- وضعية 4: وضعية جلوس عصرية وحركية (Dynamic Sitting Pose)
```

## 🚀 كيفية الرفع التلقائي على GitHub (How to Upload to GitHub)

لقد صممت لك سكريبت تلقائي اسمه `push_to_github.sh` يقوم برفع كل هذه الملفات والمجلدات وتحديثها على مستودعك في GitHub بضغطة زر واحدة!

### الخطوات البسيطة لتشغيل السكريبت:

1. قم بفتح الـ Terminal الخاص بك.
2. تأكد من أنك في مساحة العمل، ثم قم بتشغيل الأمر التالي:
   ```bash
   bash push_to_github.sh
   ```
3. سيطلب منك السكريبت إدخال:
   * **GitHub Username**: اسم حسابك على جيت هاب.
   * **GitHub Repository Name**: اسم المستودع الذي تريد الرفع عليه (مثال: `streetwear-catalog`).
   * **GitHub Personal Access Token (PAT)**: رمز المرور الخاص بك (Token) لتأمين الاتصال والرفع بأمان.

## 🛠️ تفاصيل المعالجة الرقمية (Digital Processing Details)

* **إزالة الخلفية (Background Removal):** تم استخدام سكريبت معالجة صور ذكي (`bg_remover.py`) يعتمد على مكتبات OpenCV و PIL للقيام بعملية اقتصاص احترافية (Flood-fill thresholding) لضمان الحفاظ على تفاصيل وأطراف التيشيرت والموديل ناعمة وبدون أي رتوش بيضاء، لتندمج الصور بسلاسة في موقع شوبيفاي مع أي خلفية تختارها.
* **ثبات الموديل (Model Consistency):** جميع الوضعيات الأربعة للموديل تم توليدها باستخدام نفس مواصفات وبنية الجسم (Streetwear fit)، وتم اقتصاص الوجه بدقة متناهية من عند الرقبة (Faceless) لإبراز المنتج فقط مع الحفاظ على الهوية البصرية للبراند.
